<task id="1" type="code" effort="L">
**Rebuild homepage layout to match forside-v4.html**

The page structure from the prototype (top to bottom):

1. **Hero (CMS)** — Fullscreen variant, bottom-aligned text, dual CTA ("Se tilgjengelige opplevelser" + "Besok butikk"), scroll indicator
2. **Trust bar (CMS)** — Dark inline bar with 4 items (Trygg betaling, Norsk kvalitet, Lokale guider, Gratis kansellering)
3. **Categories (page-level)** — 3 cards with 3/4 aspect ratio, gradient overlay, title+desc+hover arrow. Links to /opplevelser/retreat, /opplevelser/kurs, /opplevelser/matopplevelse
4. **Experiences (CMS)** — Section header "Kurs og Retreater" + filter tabs + detailed experience cards. Uses ExperiencesGridSection.
5. **Products (CMS)** — Section header "Produkter fra norsk natur" + 4-column product grid. Uses ProductsGridSection.
6. **Testimonials (page-level)** — 3 testimonial cards with stars, quote, author, role
7. **Blog (CMS)** — Section header "Fra bloggen" + 3-column grid (first card featured). Uses ArticlesGridSection.
8. **Newsletter (page-level)** — Dark forest bg, centered h2+p, email input + button
9. **CTA (CMS)** — "Klar for en opplevelse?" with bg image

**Implementation approach:**
- Fetch `getPageContent('forside')` for CMS sections
- Render CMS sections via SectionRenderer in the correct order
- Insert page-level components (categories, testimonials, newsletter) between CMS sections
- Keep CATEGORIES and TESTIMONIALS constants in the page file

**Section order in mock data:**
0. hero (fullscreen variant — needs ctaText + ctaLink + ctaSecondaryText/ctaSecondaryLink)
1. trust-bar (dark, 4 items)
2. experiences-grid (heading: "Kurs og Retreater")
3. products-grid (heading: "Produkter fra norsk natur")
4. articles-grid (heading: "Fra bloggen")
5. cta (heading: "Klar for en opplevelse?", with bg image)

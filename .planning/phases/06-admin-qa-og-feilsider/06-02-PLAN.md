Step 1: Read src/components/ui/FormError.tsx. Determine what selector to use:
  - If FormError renders with role="alert" → use selector `[role="alert"]`
  - If FormError renders with aria-live → use selector `[aria-live]`
  - Otherwise → add a `data-error="true"` prop to FormError and use selector `[data-error]`

  Prefer using the existing ARIA role. Do NOT change FormError.tsx to add data attributes if role="alert" already works as a selector.

Step 2: In each page's submitForm function, replace the existing `else if (result.errors)` branch with:

```typescript
} else if (result.errors) {
  setErrors(result.errors)
  if (result.errors._form) {
    toast.error(result.errors._form)
  }
  // Scroll to first visible error
  requestAnimationFrame(() => {
    const firstError = document.querySelector('[role="alert"]')
    if (firstError) {
      firstError.scrollIntoView({ behavior: 'smooth', block: 'center' })
      // If the element is focusable, focus it for screen reader announcement
      if (firstError instanceof HTMLElement && firstError.tabIndex >= 0) {
        firstError.focus()
      }
    }
  })
}
```

Apply the same change to all three files:
  - src/app/admin/produkter/ny/page.tsx — replace the existing `else if (result.errors)` branch (may already have toast.error; ensure the scroll logic is added)
  - src/app/admin/opplevelser/ny/page.tsx — replace the existing branch (currently only has `setErrors(result.errors)`)
  - src/app/admin/artikler/ny/page.tsx — replace the existing branch (currently only has `setErrors(result.errors)`)

Important: Do not use setTimeout with a fixed delay. Use requestAnimationFrame — it fires after the next render cycle. If scrollIntoView with smooth behavior is not available (SSR guard), wrap in `if (typeof window !== 'undefined')`.

The behavior must work for:
  - Submitting with no name (error appears near top of form)
  - Submitting with no image (error appears mid-form, below the image section)
  - Submitting with all fields missing (_form error appears at very top)

The smooth scroll brings the FIRST error (topmost in the DOM) into the viewport's center.

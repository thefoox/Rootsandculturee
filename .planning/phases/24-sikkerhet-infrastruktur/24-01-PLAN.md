Create NEW file src/proxy.ts. This is the Next.js 16 replacement for middleware.ts. It MUST:

1. Export a function named `proxy` (NOT `middleware`) that accepts `NextRequest` and returns `NextResponse | Response`.
2. Export a `config` object with `matcher` array.
3. Use Edge Runtime compatible code ONLY — no Node.js APIs, no firebase-admin imports, no server-only imports.

Rate limit configuration (module-level Map, keyed by `${ip}:${bucket}`):
- `/api/auth/login`: 10 requests per 60,000ms (10/min)
- `/api/auth/google`: 10 requests per 60,000ms (10/min)
- `/api/auth/session`: 30 requests per 60,000ms (30/min — higher because client polls this)
- `/api/upload`: 20 requests per 3,600,000ms (20/hr)

Rate limit logic:
- Extract IP from `x-forwarded-for` (first entry, trimmed) falling back to `x-real-ip`, then `'unknown'`.
- Module-level `Map<string, { count: number; resetAt: number }>`.
- On each request: if no entry or `now > resetAt`, create fresh entry with count=1. If `count >= max`, return 429. Otherwise increment count.
- 429 response: `NextResponse.json({ error: 'For mange forsok. Prov igjen senere.' }, { status: 429 })`.
- Add `Retry-After` header to 429 response: `Math.ceil((entry.resetAt - now) / 1000)` seconds.
- If not rate-limited: `return NextResponse.next()`.

Request logging:
- `console.log(\`[proxy] ${request.method} ${pathname} ip=${ip}\`)` for all matched routes.

Matcher config:
```typescript
export const config = {
  matcher: [
    '/api/auth/login',
    '/api/auth/google',
    '/api/auth/session',
    '/api/upload',
  ],
}
```

IMPORTANT CAVEAT to document in a code comment: In-memory Map resets on Vercel Edge cold starts. This is acceptable for abuse prevention but not strict quota enforcement. For production-grade distributed limiting, upgrade to Upstash Redis.

CSP directives:
```
default-src 'self';
script-src 'self' https://js.stripe.com${isDev ? " 'unsafe-eval'" : ''};
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
img-src 'self' blob: data: https://firebasestorage.googleapis.com https://storage.googleapis.com;
font-src 'self' https://fonts.gstatic.com;
connect-src 'self' https://*.googleapis.com https://securetoken.googleapis.com https://identitytoolkit.googleapis.com https://api.stripe.com wss://*.firebaseio.com;
frame-src https://js.stripe.com;
object-src 'none';
base-uri 'self';
form-action 'self';
frame-ancestors 'none';
upgrade-insecure-requests;
```

Add `const isDev = process.env.NODE_ENV === 'development'` before the CSP string.

Key CSP decisions:
- `script-src`: 'self' + Stripe JS. Dev gets 'unsafe-eval' for Next.js HMR. No nonces needed (app has no custom inline scripts).
- `style-src`: 'unsafe-inline' required for Tailwind runtime + Google Fonts.
- `connect-src`: Firebase Auth (securetoken, identitytoolkit), Firestore (googleapis), Firebase Realtime (wss://firebaseio.com for onSnapshot), Stripe API.
- `frame-src`: Stripe iframes for checkout/Elements.
- `frame-ancestors 'none'`: reinforces X-Frame-Options DENY.
- `form-action 'self'`: Server Actions POST to same origin.

2. **Strict-Transport-Security**: `max-age=63072000; includeSubDomains; preload`

3. **X-Permitted-Cross-Domain-Policies**: `none`

Final headers array should have 8 entries total (5 existing + 3 new). Do NOT remove or change any existing header.

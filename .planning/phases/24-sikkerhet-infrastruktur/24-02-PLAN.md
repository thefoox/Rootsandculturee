**Step A — Create NEW file src/lib/rate-limit.ts:**

This helper is for Server Actions only (not proxy.ts — proxy has its own Map). It uses `headers()` from `next/headers` to extract the client IP.

```typescript
import { headers } from 'next/headers'

type RateEntry = { count: number; resetAt: number }
const store = new Map<string, RateEntry>()

/**
 * In-memory rate limiter for Server Actions.
 * Uses headers() to extract client IP.
 *
 * CAVEAT: In-memory Map resets on serverless cold starts.
 * Acceptable for abuse prevention, not strict enforcement.
 * Upgrade path: Upstash Redis + @upstash/ratelimit.
 *
 * @returns true if rate limited (caller should return error), false if OK
 */
export async function checkActionRateLimit(
  bucket: string,
  max: number,
  windowMs: number
): Promise<boolean> {
  const headerStore = await headers()
  const ip =
    headerStore.get('x-forwarded-for')?.split(',')[0]?.trim() ??
    headerStore.get('x-real-ip') ??
    'unknown'

  const key = `${ip}:${bucket}`
  const now = Date.now()
  const entry = store.get(key)

  if (!entry || now > entry.resetAt) {
    store.set(key, { count: 1, resetAt: now + windowMs })
    return false
  }
  if (entry.count >= max) return true
  entry.count++
  return false
}
```

Insert this block between `const rawBuffer = Buffer.from(await file.arrayBuffer())` and `const isRaster = ...`:

```typescript
// Reject animated WebP — can be very large and cause DoS during processing
if (ext === '.webp') {
  const meta = await sharp(rawBuffer).metadata()
  if ((meta.pages ?? 1) > 1) {
    return NextResponse.json(
      { error: 'Animerte WebP-filer er ikke tillatt.' },
      { status: 400 }
    )
  }
}
```

Key details:
- `sharp(rawBuffer).metadata()` returns a Metadata object with optional `pages` property.
- For animated WebP, `pages` will be > 1 (each animation frame is a "page").
- For static WebP, `pages` is 1 or undefined.
- The `?? 1` fallback handles undefined as "not animated".
- This check runs BEFORE the resize/webp pipeline so animated files never enter processing.
- Do NOT add `.webp({ animated: false })` to the output pipeline — the research explicitly says this is not a valid option. The metadata check is the correct approach.

No other changes to the upload route.

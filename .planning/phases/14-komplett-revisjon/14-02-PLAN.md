**Fix:** Rewrite to follow the `[slug]/page.tsx` pattern — fetch `getPageContent('om-oss')` and render all sections via `SectionRenderer`:

```tsx
import { getPageContent } from '@/lib/data/page-content'
import { SectionRenderer } from '@/components/sections/SectionRenderer'

export default async function OmOssPage() {
  const page = await getPageContent('om-oss')
  if (!page) return <div>Innhold ikke tilgjengelig</div>

  return (
    <>
      {page.sections
        .sort((a, b) => a.order - b.order)
        .map((section) => (
          <SectionRenderer key={section.id} section={section} />
        ))}
    </>
  )
}
```

Keep the `metadata` export and `revalidate = 3600` for SEO.

Verify they accept the data format from the mock data sections. If the `ValuesSection` expects `items` array with specific shape, ensure mock data matches.

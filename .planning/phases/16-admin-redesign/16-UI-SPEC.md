## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline chip spacing |
| sm | 8px | Between label and value in stat cards, list item gaps |
| md | 16px | Card internal padding (mobile), sidebar item horizontal padding |
| lg | 24px | Card internal padding (desktop), section header bottom margin |
| xl | 32px | Gap between dashboard sections (stat grid → table sections) |
| 2xl | 48px | Not used in admin context |
| 3xl | 64px | Not used in admin context |

Exceptions:
- Nav item touch target height: 44px (WCAG 2.1 AA minimum — not an 8-point multiple, required by accessibility law)
- Sidebar collapsed width: 64px (icon-only mode — 16px icon + 24px horizontal padding each side)
- Sidebar expanded width: 240px (current value, retained)
- Mobile top bar height: 56px (current value, retained)
- Collapse toggle button: 44px × 44px touch target

## Sidebar Collapse Interaction Contract

This is the primary new interaction in Phase 16.

### Collapsed State (64px wide)
- Show icons only — no text labels
- Icons: use lucide-react equivalents for each nav item (see Icon Map below)
- Section header labels (INNHOLD, ORDRE & KUNDER) hidden
- Collapse toggle button visible at top-right of sidebar: shows `ChevronRight` icon (pointing right = expand)
- Logo / wordmark area: show initials "R" or brand mark only
- Footer: show icons only for "← Tilbake til nettbutikk" (use `ArrowLeft`) and "Logg ut" (use `LogOut`)
- Tooltip on hover for each icon: label in Norwegian, positioned to the right of the icon (role="tooltip", accessible)

### Expanded State (240px wide)
- Show icons + text labels side by side
- Collapse toggle button at top-right of sidebar: shows `ChevronLeft` icon (pointing left = collapse)
- Section headers visible
- Footer links show icon + text

### Toggle Mechanics
- State stored in `useState` on `AdminShell` — passed as prop to `AdminSidebar`
- `collapsed` prop: boolean
- Transition: `motion-safe:transition-[width] motion-safe:duration-200` — respects `prefers-reduced-motion`
- Content area adjusts: `flex-1` handles remaining width automatically
- Toggle button: `aria-label="Skjul navigasjon"` when expanded, `aria-label="Vis navigasjon"` when collapsed
- Toggle button: `aria-expanded={!collapsed}` on the `<aside>` element OR as an attribute on the button element

## Accessibility Contract (WCAG 2.1 AA)

- All nav items: minimum 44px touch target height — maintained from current implementation
- Collapse toggle: 44px × 44px — enforced via `h-[44px] w-[44px]`
- `<aside>` element: `aria-label="Admin-navigasjon"` — maintained
- Active page indicator: `aria-current="page"` on active `<Link>` — maintained
- Collapse toggle: `aria-expanded` attribute on button reflecting current sidebar state
- Collapsed icon-only mode: each icon `<Link>` must have `aria-label` equal to the nav item label (because visible text is hidden)
- Focus ring: 2px `--color-forest` outline — maintained (remove `dark-surface` class override)
- Color contrast sidebar text: `--color-forest` (#1B4332) on white (#FFFFFF) — contrast ratio ~8.5:1, exceeds 4.5:1 AA requirement
- Color contrast active item: `--color-forest` on `--color-card` (#F5F0E8) — passes AA
- Motion: collapse width animation uses `motion-safe:` Tailwind modifier to respect `prefers-reduced-motion`
- No `<div onClick>` — all interactive elements are `<button>` or `<Link>`

  <name>Task 2: Add HTTP security headers to next.config.ts</name>
  <files>next.config.ts</files>
  <action>
    Add an `async headers()` function to next.config.ts. The headers must apply to all routes
    (matcher: `'/(.*)'`). The existing `images` config must be preserved.

    Add these headers:
    - `X-Frame-Options: DENY` — prevents clickjacking
    - `X-Content-Type-Options: nosniff` — prevents MIME-type sniffing
    - `Referrer-Policy: strict-origin-when-cross-origin` — safe referrer for external links
    - `Permissions-Policy: camera=(), microphone=(), geolocation=()` — disable unused device APIs
    - `X-DNS-Prefetch-Control: on` — performance hint, safe to enable
    - Content-Security-Policy (permissive initial, suitable for Firebase + Stripe):
      ```
      default-src 'self';
      script-src 'self' 'unsafe-inline' 'unsafe-eval' https://js.stripe.com https://apis.google.com;
      style-src 'self' 'unsafe-inline';
      img-src 'self' data: blob: https://firebasestorage.googleapis.com https://storage.googleapis.com;
      connect-src 'self' https://api.stripe.com https://firebasestorage.googleapis.com https://identitytoolkit.googleapis.com https://securetoken.googleapis.com https://*.googleapis.com;
      frame-src https://js.stripe.com https://hooks.stripe.com;
      font-src 'self' data:;
      ```
      Use `unsafe-inline` and `unsafe-eval` for scripts because Next.js injects inline scripts
      and Stripe.js requires eval. This is the correct starting point — do not tighten further
      in this phase.

    The final config shape:
    ```typescript
    const config: NextConfig = {
      images: { remotePatterns: [...] },
      async headers() {
        return [
          {
            source: '/(.*)',
            headers: [
              { key: 'X-Frame-Options', value: 'DENY' },
              { key: 'X-Content-Type-Options', value: 'nosniff' },
              { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
              { key: 'Permissions-Policy', value: 'camera=(), microphone=(), geolocation=()' },
              { key: 'X-DNS-Prefetch-Control', value: 'on' },
              {
                key: 'Content-Security-Policy',
                value: "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval' https://js.stripe.com https://apis.google.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https://firebasestorage.googleapis.com https://storage.googleapis.com; connect-src 'self' https://api.stripe.com https://firebasestorage.googleapis.com https://identitytoolkit.googleapis.com https://securetoken.googleapis.com https://*.googleapis.com; frame-src https://js.stripe.com https://hooks.stripe.com; font-src 'self' data:;"
              },
            ],
          },
        ]
      },
    }
    ```

**Fix 1 — checkout/page.tsx: Remove the 500ms setTimeout race in empty-cart redirect.**

Current code has:
```typescript
const timer = setTimeout(() => {
  if (items.length === 0 && !paymentIntentId) {
    router.push('/handlekurv')
  }
}, 500)
```
This is fragile — 500ms may not be enough for localStorage hydration on slow devices. Replace with a `mounted` flag from CartProvider to distinguish "not yet loaded" from "genuinely empty":

The CartProvider already exposes `items` — add a `mounted` state to CartProvider context. Actually, looking at CartProvider, it sets `mounted = true` after `setItems(loadCart())` in a useEffect. Expose `mounted` from CartProvider context so checkout page can wait for it:

In `src/components/cart/CartProvider.tsx`, add `mounted` to `CartContextValue` and return it from the provider value. Then in CheckoutPage, replace the setTimeout with:
```typescript
useEffect(() => {
  if (!mounted) return
  if (items.length === 0 && !paymentIntentId) {
    router.push('/handlekurv')
  }
}, [mounted, items.length, paymentIntentId, router])
```
This is race-condition-free: it only redirects once `mounted = true` (localStorage has loaded).

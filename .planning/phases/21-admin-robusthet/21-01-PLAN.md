Add an `isDirty` state tracker and `beforeunload` useEffect to each of the 6 create/edit pages. The pattern is adapted from `src/app/admin/innhold/[pageId]/page.tsx` (lines 562-571).

For each page, add:

1. A `const [isDirty, setIsDirty] = useState(false)` state variable.

2. A `useEffect` that sets `isDirty = true` whenever any form field changes AFTER initial load. The simplest approach: add an `isLoaded` ref for edit pages that starts `false` and is set `true` once loading completes. For create pages, track if any field has been touched (any setter called by user interaction).

   **For CREATE pages** (produkter/ny, opplevelser/ny, artikler/ny):
   Use a `useRef(false)` called `hasInteracted`. Set it to `true` inside the first user-triggered onChange. Then add a `useEffect` that watches all form state values: if `hasInteracted.current` is true and any value is non-empty, set `isDirty(true)`. Reset `isDirty` to false right before calling `submitForm`.

   Simpler approach: just track `isDirty` directly. On create pages, the form starts empty. Any change means dirty. Add a single `useEffect` that depends on ALL state variables (name, slug, description, price, etc.) and sets `isDirty(true)` if any is non-default. Use a `mounted` ref to skip the first render:
   ```tsx
   const mounted = useRef(false)
   useEffect(() => {
     if (!mounted.current) { mounted.current = true; return }
     setIsDirty(true)
   }, [name, slug, description, price, ...all other state fields])
   ```

   **For EDIT pages** (produkter/[id], opplevelser/[id], artikler/[id]):
   Same pattern but also skip the initial hydration from the useEffect that loads data. Use a `loaded` ref that is set `true` at the end of the data-loading `.then()` block, after all `set*()` calls. Then the dirty-tracking `useEffect` only sets `isDirty(true)` when `loaded.current` is true:
   ```tsx
   const loaded = useRef(false)
   // In the data-loading .then():
   // ... setName(product.name) etc ...
   // loaded.current = true  // <-- add this AFTER all setters, BEFORE setLoading(false)
   
   useEffect(() => {
     if (!loaded.current) return
     setIsDirty(true)
   }, [name, slug, description, price, ...all other state fields])
   ```

3. The beforeunload guard useEffect (identical for all 6 pages):
   ```tsx
   useEffect(() => {
     if (!isDirty) return
     const handler = (e: BeforeUnloadEvent) => {
       e.preventDefault()
       e.returnValue = ''
     }
     window.addEventListener('beforeunload', handler)
     return () => window.removeEventListener('beforeunload', handler)
   }, [isDirty])
   ```

Wrap the unprotected Firestore calls in the 3 delete actions with try/catch blocks.

**src/actions/products.ts — `deleteProduct`** (line 203-212):
Currently the function has a raw `await adminDb.collection('products').doc(id).delete()` with no try/catch. Wrap it:
```typescript
export async function deleteProduct(id: string): Promise<ActionResult> {
  const session = await verifySession()
  if (!session || session.role !== 'admin') {
    return { success: false, error: 'Ikke autorisert.' }
  }

  try {
    await adminDb.collection('products').doc(id).delete()
    revalidateTag('products', 'max')
    return { success: true }
  } catch (err) {
    console.error('[deleteProduct] Firestore delete failed:', err)
    return { success: false, error: 'Kunne ikke slette produktet. Prov igjen.' }
  }
}
```

**src/actions/experiences.ts — `deleteExperience`** (line 292-311):
Same pattern. The function deletes subcollection docs then main doc. Wrap the entire block:
```typescript
export async function deleteExperience(id: string): Promise<ActionResult> {
  const session = await verifySession()
  if (!session || session.role !== 'admin') {
    return { success: false, error: 'Ikke autorisert.' }
  }

  try {
    // Delete dates subcollection first
    const datesSnapshot = await adminDb
      .collection(`experiences/${id}/dates`)
      .get()
    const batch = adminDb.batch()
    datesSnapshot.docs.forEach((doc) => batch.delete(doc.ref))
    await batch.commit()

    // Delete main doc
    await adminDb.collection('experiences').doc(id).delete()
    revalidateTag('experiences', 'max')
    revalidateTag('experience-dates', 'max')
    return { success: true }
  } catch (err) {
    console.error('[deleteExperience] Firestore delete failed:', err)
    return { success: false, error: 'Kunne ikke slette opplevelsen. Prov igjen.' }
  }
}
```

export async function deleteArticle(id: string): Promise<ActionResult> {

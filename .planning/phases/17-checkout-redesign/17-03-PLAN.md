
The session payload (from `getSession()`) contains `{ uid, email, role, expiresAt }`. Add `email` to the response:
```typescript
import { NextResponse } from 'next/server'
import { getSession } from '@/lib/session'

export async function GET() {
  const session = await getSession()
  if (!session) {
    return NextResponse.json({ authenticated: false })
  }
  return NextResponse.json({
    authenticated: true,
    role: session.role,
    email: session.email,
  })
}
```

This is a safe change -- the email is the user's own session data, no information leak.

Create a local helper function for initials:
```typescript
function getInitials(email: string | null): string {
  if (!email) return '?'
  // If it looks like an email, use first letter
  if (email.includes('@')) {
    return email[0].toUpperCase()
  }
  // If it's a name with spaces, use first + last initial
  const parts = email.trim().split(/\s+/)
  if (parts.length >= 2) {
    return (parts[0][0] + parts[parts.length - 1][0]).toUpperCase()
  }
  return email[0].toUpperCase()
}
```


The `list-none [&::-webkit-details-marker]:hidden` removes the default browser disclosure triangle. The `flex items-center justify-between` positions the text and chevron.

```jsx
<details
  className="lg:hidden"
  open={summaryOpen}
  onToggle={(e) => setSummaryOpen((e.target as HTMLDetailsElement).open)}

>
```

This uses the existing `summaryOpen` React state (already tracked via onToggle) to drive the ChevronDown rotation.

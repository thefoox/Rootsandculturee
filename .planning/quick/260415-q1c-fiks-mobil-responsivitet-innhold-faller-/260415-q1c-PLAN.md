**Issue 2 — StatsSection grid overflow (StatsSection.tsx):**
On line 20, change the grid classes from:
`grid grid-cols-2 gap-8`
to:
`grid grid-cols-1 gap-6 sm:grid-cols-2 sm:gap-8`

This makes stats stack vertically on phones (below 640px), preventing the large clamp text-h1 numbers from overflowing narrow 2-column cells. At sm (640px+) it returns to 2-col with the original gap-8.

**Issue 3 — TextImageSection zero mobile spacing (TextImageSection.tsx):**
In ALL layout variants that use `max-md:space-y-0`, replace with appropriate mobile spacing. The `max-md:space-y-0` class removes all vertical gap between the image and text card when stacking on mobile, making them sit flush. Fix each:

- **OverlapLayout** (line 66): Change `max-md:space-y-0` to nothing (remove it entirely). The md:grid already handles desktop layout; on mobile without grid the elements will naturally stack. The text card div already has `max-md:p-8` for padding.

- **SplitLayout** (line 93): Same — remove `max-md:space-y-0`. On mobile the elements stack naturally.

- **ContainedLayout** (line 118): Same — remove `max-md:space-y-0`. The outer card div with rounded-3xl and bg-card contains everything, so natural stacking works.

- **OffsetLayout** (line 189): Same — remove `max-md:space-y-0`.

In each case, just delete the `max-md:space-y-0` from the className string. Do NOT add a replacement spacing class — the grid/flex children stack naturally with their own padding (max-md:p-8) providing the visual separation.

**Issue 5 — ContactInfoSection negative margin too aggressive (ContactInfoSection.tsx):**
On line 13, change `-mt-12` to `-mt-6 md:-mt-12`. This reduces the upward pull on mobile from 48px to 24px, preventing the stacked contact cards from clipping into the hero section above.

**Issue 7 — HeroOverlayLayout justify on mobile (TextImageSection.tsx):**
On lines 171-172, the flex container uses `justify-start` or `justify-end` depending on imageOnRight. Add `max-md:justify-center` to center the floating text card on mobile viewports regardless of image position. Change the className on line 171 to include `max-md:justify-center` before the conditional justify class. The line should become:
```
className={`relative z-[2] flex min-h-[500px] items-center max-md:justify-center px-6 py-20 md:min-h-[600px] md:px-12 ${
  imageOnRight ? 'justify-start' : 'justify-end'
}`}
```

Wait — `max-md:justify-center` would be overridden by the unconditional `justify-start`/`justify-end`. Instead, make the justify conditional on md:
```
className={`relative z-[2] flex min-h-[500px] items-center justify-center px-6 py-20 md:min-h-[600px] md:px-12 ${
  imageOnRight ? 'md:justify-start' : 'md:justify-end'
}`}
```

This centers on mobile (justify-center is the base) and applies the directional justify only at md+.
